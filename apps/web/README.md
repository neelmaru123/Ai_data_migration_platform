# AI Data Migration Platform — Frontend Web Application

Next.js 14 App Router application built with TypeScript, Tailwind CSS, React Query, and React Flow.

## Navigation & Workflows

1. **Dashboard (`/`)**: System overview, active sources, quick statistics.
2. **Data Sources (`/sources`)**: Connect PostgreSQL, MSSQL, CSV, or Excel sources.
3. **Dataset Profiling (`/profiling`)**: Memory-efficient schema profiling and null/unique distributions.
4. **Transformation Plan (`/transformation-plan`)**: AI schema mapping review, plan approval, and operation customization.
5. **Execution (`/execution`)**: Cloud worker migration monitor and local script generator package download.
